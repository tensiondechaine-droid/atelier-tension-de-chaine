Comment la machine calcule

How the machine works it out

计算原理

L = √( W² + (P/2)² + (E/2)² − 2 · P/2 · E/2 · cos(720° · X / N) ) − s/2

W : distance centre → flasque, corrigée du déport de la jante. P : Ø de perçage du flasque. E : ERD. X : croisements. N : nombre de rayons. s : Ø du trou dans le flasque. Pour la tension, on équilibre les forces latérales des deux côtés ; pour l’allongement, la loi de Hooke avec l’acier inox (210 GPa).

W: centre-to-flange distance, corrected for rim offset. P: flange PCD. E: ERD. X: crosses. N: spoke count. s: flange hole diameter. Tension balances the lateral forces of both sides; stretch uses Hooke’s law with stainless steel (210 GPa).

W：中心到法兰距离（已按轮圈偏移修正）。P：法兰孔圆直径。E：ERD。X：交叉数。N：辐条数。s：法兰孔径。张力按两侧横向力平衡计算；伸长量用胡克定律（不锈钢 210 GPa）。
